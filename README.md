📊 Sobre o Projeto

O TECH TRENDS é um projeto de análise de dados voltado para marketing digital, desenvolvido utilizando Power BI para criação de dashboards interativos, modernos e estratégicos.

O principal objetivo é transformar dados de campanhas, tráfego e comportamento de usuários em insights acionáveis, auxiliando equipes de marketing e negócios na tomada de decisão baseada em dados.
